## 📌 Sobre o projeto

O **Sul Multas** é um projeto de desenvolvimento web criado com o objetivo de apresentar os serviços de uma empresa especializada em recursos e soluções relacionadas ao trânsito.

O projeto foi desenvolvido buscando criar uma experiência visual simples, profissional e intuitiva, permitindo que o usuário encontre rapidamente informações sobre os serviços oferecidos, tipos de infrações e formas de contato.

Além da parte visual, o projeto também foi uma oportunidade para aplicar na prática conhecimentos de **HTML, CSS e JavaScript**, trabalhando com organização de conteúdo, navegação entre seções, responsividade e interação com o usuário.

---

## 🎯 Objetivo

O principal objetivo do projeto foi desenvolver uma página institucional que apresentasse:

- Os principais serviços oferecidos;
- Diferentes tipos de infrações de trânsito;
- Informações sobre as soluções oferecidas;
- Depoimentos/apresentação de clientes;
- Formas de contato;
- Uma navegação simples e intuitiva.

O projeto também serviu como prática para transformar conhecimentos estudados em um projeto mais próximo de uma aplicação real.

# 🛠️ Serviços

A seção **Serviços** apresenta as principais soluções oferecidas pela empresa.

Entre elas estão:

- Suspensão e cassação da CNH;
- Recursos de infrações de trânsito;
- Indicação de condutor infrator;
- Gestão de frota para empresas.

Cada serviço possui uma descrição explicando de forma resumida sua finalidade.

<img width="1835" height="884" alt="image" src="https://github.com/user-attachments/assets/56d84bca-6c41-41b8-a23e-025e351dd349" />


### O que foi aplicado nessa seção?

Nesta parte do projeto trabalhei principalmente com:

- Estruturação de conteúdo utilizando HTML;
- Organização dos elementos utilizando CSS;
- Ícones para representar visualmente cada serviço;
- Imagens para complementar o conteúdo;
- Organização responsiva da página.

A utilização de ícones ajuda o usuário a identificar visualmente cada serviço antes mesmo de ler sua descrição.

# 🚨 Infrações

A seção **Infrações** apresenta diferentes tipos de infrações de trânsito que podem ser trabalhadas pela empresa.

O usuário pode navegar entre diferentes opções de infrações através dos botões disponíveis na seção.

Exemplos apresentados no projeto:

- Arrancada brusca;
- Ameaçar pedestre;
- Avançar sinal;
- Ultrapassar pelo acostamento;
- Ultrapassar pela linha contínua.

  <img width="1825" height="879" alt="image" src="https://github.com/user-attachments/assets/477bf96c-e95a-46b6-9760-18be57b184b2" />


### ⚙️ Como funciona?

Cada opção representa uma infração diferente.

A interação permite alterar o conteúdo apresentado de acordo com a infração selecionada, mostrando:

- Nome da infração;
- Imagem relacionada;
- Descrição;
- Informações sobre a penalidade.

Essa parte foi importante para aplicar conceitos de **JavaScript e manipulação do DOM**, trabalhando com elementos da página e suas classes.
